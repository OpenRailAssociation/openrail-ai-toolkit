# Official OpenRail project list

The authoritative list of OpenRail projects is maintained in the [technical-committee repo](https://github.com/OpenRailAssociation/technical-commitee):

    docs/joining/projects.md

It records all incubated projects (stage 1, stage 2) and administrative projects, including their repositories and acceptance dates.

The [website repo's](https://github.com/OpenRailAssociation/website) `data/projects.yml` is derived from this list. It references publiccode.yml files and drives the project display on openrailassociation.org.

When checking which projects exist or whether a new project has been accepted, use the TC file as the source of truth.

The official list is published at https://projects.openrailassociation.org/docs/joining/projects/.
