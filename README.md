# OpenRail AI Toolkit

This repo contains material, templates, instructions, and tools useful when working with AI agents on OpenRail topics.

## Contents

### Incubation Review Skill

A structured procedure for reviewing project applications to the OpenRail incubation process. It covers setting up a review workspace, running automated checks (license scans, vulnerability scans, secrets detection, REUSE compliance), and producing a report against the stage criteria defined by the Technical Committee.

See [`skills/incubation-review/SKILL.md`](skills/incubation-review/SKILL.md) for the full documentation.

## Status

This is an experimental administrative project of the OpenRail Association. Its scope and contents may change as we learn what works well for AI-assisted workflows in the OpenRail context.
